Chat ke Spreadsheet

Ubah data dari WhatsApp menjadi tabel Excel dalam tiga langkah.

Langkah 1. Tempel data

Tempel data dari WhatsApp. Setiap pemisah (misalnya koma ,) akan menjadi kolom baru.

Contoh: 01/10/2026, D3, mesin bermasalah, Wringin Anom,Rusak. Teks dalam tanda kutip, misalnya "Andi, S.Pd", tidak dipecah.

Langkah 2. Periksa hasil dan pilih sheet

Belum ada data.

Langkah 3. Simpan ke Excel

Belum ada sheet.

File Excel otomatis dibuat rata tengah, judul berwarna, ada garis tabel dan baris selang-seling. File CSV tidak bisa menyimpan warna.

Sheet dari file akan muncul di daftar "Masukkan ke sheet", lalu data baru bisa ditambahkan ke sheet yang kamu pilih.

Sheet disimpan otomatis di browser HP ini, jadi tidak hilang saat halaman ditutup.
